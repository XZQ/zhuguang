# 店巡 Agent｜作品简介（逐光队）

店巡 Agent 面向需要受控执行与独立验收的实体业务流程，以连锁便利店冷柜失温为首个验证场景。它将设备、商品批次、停售、审批和维修事实关联到同一事件，解决“设备修好，但商品尚未满足放行条件”的协同问题。

系统由主控、巡检、诊断、执行、审计五个业务 Agent 协作，六个 P0 Skill 承载可复用能力，十二个有状态 MCP 工具连接本地设备、库存、审批和工单适配器。发现异常后先遏制，维修和商品处置按策略审批；Auditor 独立重查，IncidentService 判断业务终态，Executor 不能自证关闭。

工程实现包含事务、版本冲突控制、幂等、输出恢复、有限重试、等待唤醒与人工升级。知识候选经审核和脱敏后才发布，不自动修改业务策略。

目前六个合成冷链场景可复现，外部设备、人员和维修由有状态替身驱动。真实 AgentTeams、PolarDB、企业系统与门店收益仍需目标环境验证。本地测试不调用大模型，不将场景通过率外推为生产准确率。后续以合作方试点建立误派工单、遏制时间、证据完整率和处置成本基线，再验证复用价值。
