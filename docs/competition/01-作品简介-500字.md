## 店巡 Agent - 连锁门店异常闭环基础设施

连锁便利店冷柜失温不是一次告警，而是必须安全关闭的事件：既要判断失温原因，也要阻断受影响商品销售，并协调审批、维修、批次处置和复核。传统人工巡店依赖电话、群聊和表格，证据分散，设备恢复易被误当作商品安全，造成漏处置和责任断点。

店巡 Agent 以 AgentTeams 为协同基点，由总控、巡检、诊断、处置、稽核 5 个业务 Agent 完成“发现与遏制、诊断与决策、处置执行、独立验证、复盘演进”五阶段闭环。6 个 P0 Skill 承载可复用能力，12 个有状态 MCP 函数连接设备、库存、停售、审批和工单；受控写操作均经过 Policy、审批、幂等和审计，Executor 不得关闭事件，Auditor 必须重查设备与商品事实。

项目采用“冷柜失温主场景 + 缺货、价签补充场景”的一主两辅结构。固定 seed 的 6 个冷柜场景和 42 项测试已通过，Evidence 45/45、适用阶段 Trace 26/26，五类业务安全违规均为 0。结果基于有状态 Mock；官方 Skill 口径、AgentTeams 委派/MCP 身份绑定和企业接入仍待确认或验证。
