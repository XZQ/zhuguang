## 3. 平台取证验收单

这是准备清单，不是平台实跑记录。

| 要取得的内容 | 验收方式 |
|---|---|
| 部署版本和时间 | 源码SHA或镜像digest、Worker制品hash、版本获取命令与时间；五个Worker在线快照只是辅助 |
| 真实动态协作 | 同一任务/incident的Manager→Orchestrator→业务Worker委派、接单、输出和终态 |
| Skill调用 | 六个实际Skill的name/version/digest与对应工具调用；不能只列配置文件 |
| 身份边界 | Worker→角色→scope关联；缺凭证/错角色被拒，合法角色成功，日志脱敏 |
| 人工审批 | 指定人员在目标系统实际确认，时间和审批对象一致；ScenarioEngine审批单独标模拟 |
| 独立核验 | Auditor重新读取设备、商品、hold、工单和审批；不能复用Executor一句“已完成” |
| 异常处理 | HTTP运行接口的partial保持遏制并重查；完整核验失败才允许runtime_reopen。本地Adapter的F另会回到EXECUTE/BLOCKED；三者记录不能混用 |
| 恢复与重复请求 | 输出丢失、进程重启、旧租约拒绝、重试无重复副作用的原始记录 |

真实脱敏证据导出后，使用仓库命令 `uv run dianxun agentteams-verify <真实证据文件> --output <校验报告>`。命令通过只说明结构/关联检查通过，还需核查原始记录与录像；禁止复制测试fixture充当实际导出。

## 4. 本地演练操作单

正式决赛总时长未知，不给这份步骤表强行分配官方分钟数。可先练“主场景+异常场景”，等通知后压缩。

| 顺序 | 场景/动作 | 展示什么 | 预期结果 |
|---|---|---|---|
| 1 | A 压缩机故障 | 遏制、审批、批次处置、独立重查与审计 | CLOSED |
| 2 | E 设备恢复但商品不安全 | 设备恢复不能替代商品核验 | CONTAINED；不声称此固定场景已继续处置到关闭 |
| 3 | F 工单查询partial | 数据不全时保持停售，不错误关闭 | 本地result=reopened、CONTAINED/EXECUTE/BLOCKED；不等同于HTTP runtime_reopen |
| 4 | 恢复机制问答备用 | 实际Worker回归中的完整失败核验、受控重处置和独立关闭 | 对应回归通过；现场平台需另录 |

所有命令从仓库根目录运行。以下脚本每次建立独立临时目录，避免重置已有演示或用户数据库；需要当前虚拟环境/依赖已安装。执行前可检查`uv run dianxun demo-run --help`。

```powershell
$finalsDemoDir = Join-Path ([System.IO.Path]::GetTempPath()) ('veriagent-rehearsal-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $finalsDemoDir -ErrorAction Stop | Out-Null
$finalsScenarios = @(
    'coldchain-compressor-failure',
    'coldchain-device-recovered-goods-unsafe',
    'coldchain-workorder-query-partial'
)
foreach ($finalsScenario in $finalsScenarios) {
    uv run dianxun demo-run "demo/state/scenarios/$finalsScenario.json" --db (Join-Path $finalsDemoDir "$finalsScenario.db") --output (Join-Path $finalsDemoDir "$finalsScenario.json")
    if ($LASTEXITCODE -ne 0) { throw "演练失败：$finalsScenario" }
}
Write-Output "本次演练目录：$finalsDemoDir"
```

界面解释稿与真实平台操作分开验收：当前本地Demo不调用LLM；线上浏览器动画和移动审批按钮不能替代真实平台取证。
