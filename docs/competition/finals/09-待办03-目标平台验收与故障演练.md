## 必验故障

| 场景 | 验收结果 |
|---|---|
| Worker 断联、持续空心跳 | 原任务在截止后失效，有限重试或换实例，不能无限续期 |
| 主控卡住或重启 | 从持久化状态恢复或由服务端派发下一阶段，不重复委派 |
| 两个扫描器并发、扫描器重启 | 同一前序只有一个有效后继，已完成阶段不重复执行 |
| 旧 Worker 迟到提交 | 失效租约无法继续写业务状态或成功检查点 |
| 工单响应丢失、结果未知 | 查原始回执并保留幂等身份；未知结果进入人工核验 |
| 审批/维修长等待、超时或拒绝 | 释放执行资源，不重复建单；唤醒和升级均有记录 |
| 所有备用不可用、数据库不可用 | 有界等待或明确升级，健康检查暴露故障并限制危险写入 |
| 应急保护与正常流程汇合 | 仅在隔离演练的明确授权范围启用；保护不重复，审批与独立审计不被绕过 |
| 跨租户、跨门店、通知旧代次 | 越权和迟到请求被拒绝，无其他范围的数据泄露 |

每项记录测试环境、实际版本、注入动作、开始/结束时间、任务及回执引用、观测结果与通过/失败结论。问题修复后重跑受影响场景。正式报告明确区分真实平台证据、测试业务数据和外部系统模拟结果。
