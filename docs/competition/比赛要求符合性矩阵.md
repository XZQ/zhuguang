# 逐光｜比赛要求符合性矩阵

> 核对日期：2026-08-28（北京时间）。本矩阵以当日官网、Agent Infra 参赛手册和 AgentTeams `v1.2.3` 官方 Release 为准；官网或组委会后续通知变化时必须重新核对。

## 1. 结论

逐光的**选题方向、五阶段业务闭环、5 个业务 Agent、6 个 P0 Skill、12 个 MCP、审批审计、确定性评测和开源材料均与 Agent Infra 赛道方向一致**。仓库内已经具备可运行的本地 Demo、复赛 PPT/PDF、Worker ZIP、部署资源和复现说明。

但当前不能宣称“复赛要求已全部满足”，原因有四项：

1. AgentTeams YAML、Worker ZIP 和本地 MCP 测试尚未形成真实 Team Room、Worker 委派、平台资源 Running 状态和同一任务平台 Trace；这是最重要的外部待验证项。
2. MCP 已做非回环失败关闭、共享 Token 只读和 Actor Secret 引用，但目标 AgentTeams 的动态 Worker `gatewayKey` 尚未映射并实跑正负向鉴权；不能把静态 Secret 引用解释为身份已验证。
3. 官方材料对“阿里云官方用云 Skills”存在口径差异：官网技术要求允许官方 Skill 或自定义可复用 Skill，参赛手册 FAQ Q6 则写为“并使用阿里云官方用云 Skills”。当前 P0 使用自定义 Skill，不能自行把这一冲突解释为完全满足。
4. PolarDB/pgvector/RLS/分区/pg_cron/OSS 归档已经形成代码、SQL、overlay 和条件测试，但当前没有托管实例、OSS 外部表或真实门店知识基线，不能宣称云上已跑通或改善率已验证。

因此，当前状态应表述为：**仓库内复赛工程材料及评委反馈对应实现已齐备，真实 AgentTeams 动态证据、Worker → MCP 身份绑定、PolarDB/OSS 实跑和官方 Skill 口径仍需在提交前闭环。**

## 6. 提交前必须完成

### P0：直接影响复赛可信度

1. 在官方 AgentTeams `v1.2.3` 环境部署并保存脱敏证据：Manager、Team、5 Worker 状态，Team Room 委派消息，至少一次真实 MCP 返回，以及相同 `incident_id`/`request_id`/Trace 的端到端关联。
2. 在可信网关或 MCP Adapter 将动态 Worker Bearer 映射为正确 Actor，验证无 Token/错误 Token 被拒绝、越权动作返回 `FORBIDDEN`、正确调用审计主体可追溯；不得录入或提交 Token 原文。
3. 录制正常场景 A 和失败场景 F；失败分支必须看到 `partial` 阻断关闭、停售保持和后续责任人，不能只录成功路径。
4. 向组委会确认“官方用云 Skills”是否为复赛硬门槛；若是，选择一个对本项目必要的官方 Skill 做真实调用、失败处理和证据记录，不做装饰性堆叠。
5. 在隔离 PolarDB 测试实例按 `core → security → cron → archive` 验收：SQLite/PG 场景一致性、RLS/只读负向、pg_cron 运行记录、月分区和 OSS 外部表复制复核；保存脱敏证据，不使用生产库做 reset。

### P1：材料一致性与答辩风险

1. 已完成：将 72/70/2 测试口径、6/6 场景、45/45 Evidence、26/26 Trace、四变体消融、事故指挥台与双底座状态同步到事实 JSON、README、01～08、状态矩阵、AgentTeams README、PPT/PDF 和视频脚本。
2. 已完成：补充 `qwen3.5-plus` 的使用范围、凭证注入、费用假设、可替代模型和迁移成本，并明确本地确定性评测不调用该模型。
3. 已完成：明确冷链阈值只服务合成 Demo；真实部署必须由商品标签、企业 HACCP、设备说明书和所在地法规共同决定，详见 `docs/assessments/真实门店差距与演进路线.md`。

## 7. 可提交口径

推荐对外表述：

> 项目已完成冷柜失温主场景的本地闭环、确定性评测、AgentTeams `v1.2.3` 交付包，以及 PolarDB/pgvector/RLS/分区/pg_cron/归档的实现与验收契约；真实 AgentTeams 动态委派、身份绑定、平台 Trace、托管 PolarDB/OSS 和门店知识基线将在目标环境补证。当前指标不代表生产准确率、经营改善率或食品安全放行依据。

禁止表述：

- “AgentTeams 已真实跑通”（取得平台动态证据前）；
- “AgentTeams → MCP 身份鉴权已闭环”（取得服务端拒绝与 Actor 审计证据前）；
- “已接入真实门店 POS/WMS/IoT/审批/维修商”；
- “PolarDB、OSS 或 AgentTeams 已云上跑通”（取得目标环境证据前）；
- “RAG 已改善真实门店指标”或“自动回滚、Higress/Nacos/LoongSuite 已上线”；
- “6/6 等于生产准确率 100%”或“系统可自主决定食品放行”。
