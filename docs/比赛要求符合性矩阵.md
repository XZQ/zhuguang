# 比赛要求符合性矩阵

> 核对日期：2026-08-28（北京时间）。本矩阵以当日官网、Agent Infra 参赛手册和 AgentTeams `v1.2.3` 官方 Release 为准；官网或组委会后续通知变化时必须重新核对。

## 1. 结论

当前项目的**选题方向、五阶段业务闭环、5 个业务 Agent、6 个 P0 Skill、12 个 MCP、审批审计、确定性评测和开源材料均与 Agent Infra 赛道方向一致**。仓库内已经具备可运行的本地 Demo、复赛 PPT/PDF、Worker ZIP、部署资源和复现说明。

但当前不能宣称“复赛要求已全部满足”，原因有两项：

1. AgentTeams YAML、Worker ZIP 和本地 MCP 测试尚未形成真实 Team Room、Worker 委派、平台资源 Running 状态和同一任务平台 Trace；这是最重要的外部待验证项。
2. 官方材料对“阿里云官方用云 Skills”存在口径差异：官网技术要求允许官方 Skill 或自定义可复用 Skill，参赛手册 FAQ Q6 则写为“并使用阿里云官方用云 Skills”。当前 P0 使用自定义 Skill，不能自行把这一冲突解释为完全满足。

因此，当前状态应表述为：**仓库内复赛工程材料基本齐备，真实 AgentTeams 动态证据和官方 Skill 口径仍需在提交前闭环。**

## 6. 提交前必须完成

### P0：直接影响复赛可信度

1. 在官方 AgentTeams `v1.2.3` 环境部署并保存脱敏证据：Manager、Team、5 Worker 状态，Team Room 委派消息，至少一次真实 MCP 返回，以及相同 `incident_id`/`request_id`/Trace 的端到端关联。
2. 录制正常场景 A 和失败场景 F；失败分支必须看到 `partial` 阻断关闭、停售保持和后续责任人，不能只录成功路径。
3. 向组委会确认“官方用云 Skills”是否为复赛硬门槛；若是，选择一个对本项目必要的官方 Skill 做真实调用、失败处理和证据记录，不做装饰性堆叠。

### P1：材料一致性与答辩风险

1. 将 42 项测试、6/6 场景、45/45 Evidence、26/26 Trace 同步到事实 JSON、README、01～08、状态矩阵、AgentTeams README、PPT/PDF 和视频脚本。
2. 补充 `qwen3.5-plus` 的使用范围、凭证注入、费用假设、可替代模型和迁移成本；不得把本地确定性评测写成该模型的效果评测。
3. 明确冷链阈值只服务合成 Demo；真实部署必须由商品标签、企业 HACCP、设备说明书和所在地法规共同决定。

## 7. 可提交口径

推荐对外表述：

> 项目已完成冷柜失温主场景的本地可运行闭环、确定性评测、AgentTeams `v1.2.3` 静态部署包和开源工程材料；真实 AgentTeams 动态委派、平台 Trace 与最终录屏将在目标环境完成后补充。当前指标仅证明固定合成场景下的仓库行为，不代表生产准确率或食品安全放行依据。

禁止表述：

- “AgentTeams 已真实跑通”（取得平台动态证据前）；
- “已接入真实门店 POS/WMS/IoT/审批/维修商”；
- “RAG、自动回滚、Higress/Nacos/LoongSuite 已上线”；
- “6/6 等于生产准确率 100%”或“系统可自主决定食品放行”。
