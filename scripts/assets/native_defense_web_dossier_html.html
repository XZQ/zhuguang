01 · 要解决的问题

冷柜修好后，柜里的商品是否已经满足放行条件？设备恢复、维修回执和商品验收是不同事实。系统以独立核验决定事件能否关闭，不能让执行者用一句“完成”代替验收。

02 · 用户与业务价值

总部运营、区域督导和店长需要在告警、群消息、工单和审批之间确认进展。目标是减少人工串联、误派工单和证据缺口；实际效率、损耗和处置成本需要合作方试点建立基线。目前没有真实收益百分比或投资回收期结论。

03 · 实际架构

IncidentService 是业务状态唯一入口；Policy 约束权限与审批；StateStore 提供事务和持久化。确定性本地流程和 /runtime Worker 接口共用业务核心。

独立 ContextBus 使用 WAL；运行上下文与领域变更在业务数据库事务中提交，版本冲突拒绝旧写入。生产 PolarDB、真实 AgentTeams、POS/WMS/IoT/维修接入仍需目标环境证据。

04 · 五个业务角色

角色责任边界
Orchestrator协调阶段和委派不能自行判定业务成功
Sentry检查数据质量、发现异常不执行库存或解禁动作
Diagnoser批次风险与证据关联诊断建议不直接改变业务状态
Executor按权限和审批执行不能代替 Auditor 验收或自证关闭
Auditor独立重查和复盘证据不完整时保持限制

外层还有 1 个 Framework Manager，不计入五个业务 Agent。Human 是独立审批/运维身份，不是额外业务 Agent。

05 · 五阶段闭环

发现与遏制 → 诊断与决策 → 处置执行 → 独立验证 → 复盘。先停售遏制，再诊断；受控处置先审批，执行后重新查询事实。

比赛策略下，维修金额大于 2000 元需要相应审批；转移、放行、报损与解除停售有独立审批约束。设备恢复不能替代商品核验，LEARN 后由 IncidentService 决定关闭。

示例温控和暴露阈值只用于合成场景，不能直接判断真实食品已变质或可以售卖。

06 · 六个合成场景

场景验证重点
A 设备故障遏制、审批、处置、独立核验和关闭
B 传感器疑点数据质量与独立复测
C 柜门未关证据关联根因与受控处置
D 审批超时timeout 不等于批准，保持遏制
E 设备恢复但商品仍不安全固定场景保持 CONTAINED
F 工单查询 partial本地流程回到 EXECUTE/BLOCKED，不错误关闭

F 是有状态替身的查询不完整分支，不是 MCP 崩溃或网络压力测试。实际 HTTP 的受控 reopen 还要求完整失败核验、正确身份和版本。

07 · Skill 与工具契约

六个 P0 Skill：anomaly-detect、coldchain-risk-assess、rootcause-drilldown、work-order-dispatch、outcome-verify、review-report。每个都有输入输出 Schema、权限与失败边界；Registry/Trace 记录名称、版本和摘要。

业务工具为 12 个 P0（5 查询、7 动作）及默认关闭的 3 个知识 P1；/runtime 协调工具另行枚举。目标模型配置为 @@MODEL@@，本地六场景评测不调用模型。

08 · 安全与恢复

受控写经过身份/scope、审批、幂等和事务。解禁要求新鲜的 Auditor 核验，核验后事实变化仍会阻断关闭。响应丢失可读取 checkpoint 原输出，旧租约不能继续写。

服务端扫描器提供硬截止、进展检查、有限重试、容量选择、审批/维修等待、回执核验与人工升级。未知外部结果不能直接重做；取消模型或 HTTP 不会撤销已经发生的外部操作。

本地恢复回归与真实平台恢复分开验收。通知 Outbox 协议不是短信、飞书或邮件已经接通的证据。

09 · 可复核的证据

@@TEST_DATE@@ 记录：@@TEST_COUNT@@ 项测试发现，@@TEST_PASSED@@ 通过，@@TEST_SKIPPED@@ 项 PolarDB 条件跳过。六场景 6/6，Evidence 45/45，适用阶段 Trace 26/26；结果只适用于本地合成验收范围。

消融结论：移除 Auditor 后 5/6 场景停于 VERIFY/BLOCKED，0 放行尝试、0 错误关闭、0 不安全放行。它验证独立核验不可用时的安全阻断。

单身份消融体现当前 Policy 的受控写拒绝，不能外推所有单 Agent 架构均较差。测试通过率不是行覆盖率、模型准确率或生产安全保证。

11 · 问答边界

是否形式化验证？当前为 Schema、规则、权限、事务与回归，没有形式化证明。

支持多少设备、延迟多少？浏览器里的 128 店/512 设备是模拟布局；无真实规模或 P99 基准。默认 HTTP 32 连接、10 秒绝对截止不是吞吐承诺。

是否可直接跨行业？可复用职责与验收方式；仍需替换领域契约、策略和接口并重建验证集。

是否已经真实部署？本地证据、配置、目标平台日志和真实门店效果分别记录，不能互相替代。
